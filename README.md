# DocForge - Professional Document Generator

A powerful, browser-based document generator that creates professional PDFs for invoices, utility bills, receipts, quotes, statements, and delivery notes.

## Features

- **Multiple Document Types**: Invoice, Utility Bill, Receipt, Quote, Statement, Delivery Note
- **Company Branding**: Upload logo, set company name, address, country, tax ID
- **Client Details**: Full billing/recipient information with account references
- **Line Items**: Dynamic line items with quantity, price, and automatic totals
- **Utility Bills**: Meter readings, consumption calculation, rate per unit
- **Financial**: Tax rates, discounts, payment information, bank details
- **Customization**: Primary/accent colors, font family, font size
- **Simple View**: Form-based UI for quick document creation
- **Advanced View**: Live HTML/CSS editor with real-time preview for full control
- **PDF Export**: High-quality A4 PDF generation using html2pdf.js
- **Responsive**: Works on desktop and tablet screens
- **No Backend**: Entirely client-side - no data leaves your browser

## Usage

1. Open `index.html` in a browser
2. Select a document type
3. Fill in company and client details
4. Add line items or utility readings
5. Customize appearance (colors, fonts)
6. Switch to **Advanced View** to edit raw HTML/CSS
7. Click **Export PDF** to download

## Tech Stack

- HTML5 / CSS3 / Vanilla JavaScript
- [html2pdf.js](https://github.com/eKoopmans/html2pdf.js) for PDF generation
- [Font Awesome](https://fontawesome.com/) for icons
- [Google Fonts (Inter)](https://fonts.google.com/specimen/Inter)
